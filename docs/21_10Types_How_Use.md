## ## 프롬프트 유형과 선택 이유
```
 문제 해결의 훈련 초점은 '전략수립'입니다. 따라서 AI의 창의성을 극대화하는 동시에, 비즈니스 목표(시청 지속 시간)를 달성할 수 있도록 통제하는 4가지 유형을 전략적으로 조합해야 합니다.

1. 역할부여형 (Role-playing)
선택 이유: AI에게 '평균적인 요약기'가 아닌, '세상에서 가장 잘나가는 숏폼 PD'라는 구체적인 전문가 정체성을 부여하기 위함입니다. 이는 AI의 응답 톤(Tone)과 단어 선택, 문장 구조를 '대중적', '시각적', '자극적'으로 유도하는 가장 강력한 지시입니다.
전략: "너는 10대들의 밈(Meme)을 꿰뚫고, 복잡한 지식을 초등학생도 낄낄대며 보게 만드는 천재 숏폼 콘텐츠 PD야."

2. 제약조건형 (Constraint-based)
선택 이유: '60초', '초반 3초 후킹', '초등학생 수준 언어'는 타협 불가능한 비즈니스 제약입니다. 이 제약조건을 명확히 설정함으로써, AI가 10페이지의 방대한 정보 속에서 '핵심'만을 추출하고 '형식'에 맞추도록 강제합니다.
전략: "결과물은 정확히 60초 분량이어야 해. 스크립트의 첫 3초(첫 문장)는 무조건 시청자의 스크롤을 멈추게 해야 해."

3. 재구성/번역형 (Reformatting/Translation)
선택 이유: 우리가 필요한 것은 PDF의 '요약'이 아니라, '영상 대본'이라는 전혀 다른 포맷으로의 '번역'입니다. 이 유형을 통해 AI에게 텍스트를 오디오(내레이션)와 비주얼(화면 구성, 자막)로 분리하여 재구성하도록 지시합니다.
전략: "주어진 PDF 텍스트를 [시간 | 화면 | 내레이션 | 자막/효과음] 형식의 테이블로 변환해 줘."

4. 페르소나형 (Persona-based)
선택 이유: '역할부여'가 AI의 정체성이라면, '페르소나'는 우리가 공략할 '타겟 고객'을 정의합니다. "초등학생도 이해하는 수준"이라는 명확한 페르소나를 설정하면, AI는 '생성형', '윤리적 쟁점' 같은 어려운 단어를 '그림 그려주는 AI', 'AI가 거짓말하면 어떡하지?' 같은 직관적인 언어로 자동 변환합니다.
전략: "이 영상의 시청자는 IT에 관심 없는 13살 중학생이야. '알고리즘' 대신 '추천'이라고 말해."

```

## 작성 위해 추가 필요 요건
```
 1. 채널의 명확한 '톤 앤 매너(Tone & Manner)'
이유: 똑같은 60초 지식 요약이라도, '테크인사이드' 채널이 진지하고 세련된 정보 전달(ex. 뉴닉) 스타일인지, 유쾌하고 밈을 활용하는 스타일(ex. 1분 미만)인지에 따라 후킹 멘트와 비주얼 스타일이 완전히 달라집니다.
2. 영상의 '핵심 목표(Key Goal)' 및 '단 하나의 메시지(One Message)'
이유: 10페이지 리포트는 '미래'와 '윤리'라는 최소 두 가지 이상의 큰 주제를 다룹니다. 60초 안에 이 모든 것을 담으려 하면 이도 저도 아닌 영상이 됩니다. 이번 숏폼의 목표가 '채널 유입'인지, '전문성 과시'인지, '윤리적 화두 제시'인지 명확해야 합니다.
3. PD의 '제작 리소스(Production Resources)' 한계
이유: AI가 "할리우드급 3D 그래픽으로 AI의 뇌 구조를 보여준다"라는 대본을 써도, PD가 구현하지 못하면 소용없습니다. AI가 PD의 제작 환경(ex. 스톡 영상만 사용 가능, 본인 얼굴 출연, 인포그래픽 애니메이션 가능 등)을 알아야 '실현 가능한' 시각적 요소를 제안할 수 있습니다.
```

## 문제해결 프롬프트

너는 IT 및 테크 트렌드를 '초등학생도 이해하게' 설명하는 천재 숏폼 콘텐츠 PD다. 너의 임무는 아래에 제공된 전문적이고 딱딱한 PDF 리포트의 핵심을 추출하여, 틱톡과 릴스에서 즉시 바이럴될 수 있는 60초짜리 영상 대본을 작성하는 것이다.

[핵심 지시]
주어진 리포트의 내용을 '초등학생'이 방금 전 엄마에게 설명하는 듯한 쉬운 언어로 완벽하게 '번역'하고 '재구성'해야 한다.

[필수 제약 조건]
1.  **후킹 (Hooking):** 영상 시작 후 '3초 안에' 시청자의 스크롤을 멈출 수 있는 강력하고 자극적인 멘트(내레이션 또는 자막)가 무조건 포함되어야 한다.
2.  **분량:** 총 내레이션 시간은 55초~60초 사이로 완성되어야 한다.
3.  **타겟:** 13살 중학생이 이 영상을 보고 '오, 신기한데?'라고 느낄 수 있어야 한다.
4.  **채널 톤앤매너:** '테크인사이드' 채널은 빠르고, 직관적이며, 약간의 유머를 섞는 '스피디한 정보' 스타일을 추구한다.

[출력 형식]
아래의 4단 테이블 형식을 반드시 준수하여 대본을 작성할 것. (시각적 지시가 핵심)
